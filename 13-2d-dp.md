# 2-D Dynamic Programming & Knapsack Variations

> **Estimated Time**: 12 Days • **Pace**: 1.5–2 hours/day (Strictly 1 problem/day) • **Language**: C# (.NET 6+)

---

## 🛠️ C# Mental Model & Gotchas

### 1. 2D Memory Representation: Jagged `int[][]` vs Rectangular `int[,]`
In C#:
- `int[,] matrix = new int[m, n]` allocates a single contiguous memory block. Indexing involves a slight multiplication penalty per access.
- `int[][] jagged = new int[m][]` requires allocating an array of arrays.
- **The Optimal 1D Rolling Array**: In almost all 2D DP problems where $dp[i][j]$ depends only on row $i$ and row $i - 1$, **compress the 2D matrix into a 1D array `int[] dp = new int[n]`**. This drastically reduces heap allocations and maximizes CPU cache performance.

### 2. The Knapsack Traversal Direction Invariant
When compressing a 2D Knapsack table into a 1D array `int[] dp = new int[capacity + 1]`:
- **0/1 Knapsack (Each item used AT MOST ONCE)**: Iterate capacity **BACKWARDS** from `capacity` down to `weight`:
```csharp
for (int w = capacity; w >= weight; w--) {
    dp[w] = Math.Max(dp[w], dp[w - weight] + value);
}
```
Backward iteration ensures that `dp[w - weight]` represents the state from the *previous* item, preventing the current item from being counted multiple times.
- **Unbounded Knapsack (Each item can be reused infinitely)**: Iterate capacity **FORWARDS** from `weight` up to `capacity`.

### Day 2: 2D String Alignment (Longest Common Subsequence)
- **Warm-Up (10 mins)**:
  <details>
  <summary><b>🧠 Quick Recall: In LCS, what are the two cases when comparing character $s_1[i]$ and $s_2[j]$?</b></summary>
  <br>
  <b>Answer:</b> If $s_1[i] == s_2[j]$, match! $dp[i][j] = 1 + dp[i-1][j-1]$. If $s_1[i] \ne s_2[j]$, take $\max(dp[i-1][j], dp[i][j-1])$.
  </details>
- **Deep Practice (75–85 mins) | Problem 2**:
  - [Longest Common Subsequence](https://leetcode.com/problems/longest-common-subsequence/) (NeetCode - Medium)
  - Thinking prompts: Bottom-up 2D table or 1D rolling array with `prevDiagonal` variable.
- **Reference Solution**:
  <details>
  <summary><b>View Optimal C# Solution & Complexity</b></summary>

  ```csharp
  public class Solution {
      public int LongestCommonSubsequence(string text1, string text2) {
          int m = text1.Length, n = text2.Length;
          int[] dp = new int[n + 1];
          
          for (int i = 1; i <= m; i++) {
              int prevDiag = 0;
              for (int j = 1; j <= n; j++) {
                  int temp = dp[j];
                  if (text1[i - 1] == text2[j - 1]) {
                      dp[j] = 1 + prevDiag;
                  } else {
                      dp[j] = Math.Max(dp[j], dp[j - 1]);
                  }
                  prevDiag = temp;
              }
          }
          return dp[n];
      }
  }
  ```
  <b>Complexity:</b> Time: $O(M \cdot N)$, Space: $O(\min(M, N))$ 1D array.
  </details>

### Day 3: State Machine Dynamic Programming (Stock with Cooldown)
- **Warm-Up (10 mins)**:
  <details>
  <summary><b>🧠 Quick Recall: What are the three states in Stock Trading with Cooldown?</b></summary>
  <br>
  <b>Answer:</b> 1. <code>held</code> (holding a share); 2. <code>sold</code> (just sold today, mandatory cooldown tomorrow); 3. <code>rest</code> (empty-handed, free to buy).
  </details>
- **Deep Practice (75–85 mins) | Problem 3**:
  - [Best Time to Buy And Sell Stock With Cooldown](https://leetcode.com/problems/best-time-to-buy-and-sell-stock-with-cooldown/) (NeetCode - Medium)
  - Thinking prompts: State transitions: `held = max(held, rest - price)`, `sold = held + price`, `rest = max(rest, soldPrev)`.
- **Reference Solution**:
  <details>
  <summary><b>View Optimal C# Solution & Complexity</b></summary>

  ```csharp
  public class Solution {
      public int MaxProfit(int[] prices) {
          int held = -prices[0];
          int sold = 0;
          int rest = 0;
          
          for (int i = 1; i < prices.Length; i++) {
              int prevSold = sold;
              sold = held + prices[i];
              held = Math.Max(held, rest - prices[i]);
              rest = Math.Max(rest, prevSold);
          }
          return Math.Max(sold, rest);
      }
  }
  ```
  <b>Complexity:</b> Time: $O(N)$, Space: $O(1)$.
  </details>

### Day 4: Unbounded Knapsack Coin Combinations (Coin Change II)
- **Warm-Up (10 mins)**:
  <details>
  <summary><b>🧠 Quick Recall: Why does iterating the outer loop over coins ensure we compute combinations rather than permutations?</b></summary>
  <br>
  <b>Answer:</b> By considering coins one by one in outer loop order, each coin is added monotonically without ever picking a previously considered coin type again, eliminating duplicate ordering permutations.
  </details>
- **Deep Practice (75–85 mins) | Problem 4**:
  - [Coin Change II](https://leetcode.com/problems/coin-change-ii/) (NeetCode - Medium)
  - Thinking prompts: Outer loop over coins; inner loop iterates forward from `c` to `amount`.
- **Reference Solution**:
  <details>
  <summary><b>View Optimal C# Solution & Complexity</b></summary>

  ```csharp
  public class Solution {
      public int Change(int amount, int[] coins) {
          int[] dp = new int[amount + 1];
          dp[0] = 1; // 1 way to make amount 0
          
          foreach (int c in coins) {
              for (int a = c; a <= amount; a++) {
                  dp[a] += dp[a - c];
              }
          }
          return dp[amount];
      }
  }
  ```
  <b>Complexity:</b> Time: $O(\text{amount} \times C)$, Space: $O(\text{amount})$.
  </details>

### Day 5: Mathematical Subset Reduction (Target Sum)
- **Warm-Up (10 mins)**:
  <details>
  <summary><b>🧠 Quick Recall: How is Target Sum transformed into a standard 0/1 Subset Sum problem?</b></summary>
  <br>
  <b>Answer:</b> Partition array into positive set $P$ and negative set $N$: $\sum P - \sum N = target$. Since $\sum P + \sum N = \sum nums$, adding them yields $2 \sum P = target + \sum nums \implies \sum P = \frac{target + \sum nums}{2}$. The problem reduces to finding the number of subsets that sum to $\sum P$.
  </details>
- **Deep Practice (75–85 mins) | Problem 5**:
  - [Target Sum](https://leetcode.com/problems/target-sum/) (NeetCode - Medium)
  - Thinking prompts: Backward iteration 0/1 knapsack on subset target $S = (target + totalSum) / 2$.
- **Reference Solution**:
  <details>
  <summary><b>View Optimal C# Solution & Complexity</b></summary>

  ```csharp
  public class Solution {
      public int FindTargetSumWays(int[] nums, int target) {
          int totalSum = 0;
          foreach (int n in nums) totalSum += n;
          
          if ((totalSum + target) % 2 != 0 || totalSum < Math.Abs(target)) {
              return 0;
          }
          
          int subsetTarget = (totalSum + target) / 2;
          int[] dp = new int[subsetTarget + 1];
          dp[0] = 1;
          
          foreach (int n in nums) {
              for (int s = subsetTarget; s >= n; s--) {
                  dp[s] += dp[s - n];
              }
          }
          return dp[subsetTarget];
      }
  }
  ```
  <b>Complexity:</b> Time: $O(N \cdot S)$, Space: $O(S)$.
  </details>

### Day 6: 2D Boolean State Grid (Interleaving String)
- **Warm-Up (10 mins)**:
  <details>
  <summary><b>🧠 Quick Recall: What does $dp[i][j] = true$ represent in Interleaving String?</b></summary>
  <br>
  <b>Answer:</b> The prefix $s_1[0 \dots i-1]$ and prefix $s_2[0 \dots j-1]$ can successfully interleave to form $s_3[0 \dots i + j - 1]$.
  </details>
- **Deep Practice (75–85 mins) | Problem 6**:
  - [Interleaving String](https://leetcode.com/problems/interleaving-string/) (NeetCode - Medium)
  - Thinking prompts: Quick check `s1.Length + s2.Length == s3.Length`. Compress 2D table into a 1D boolean array.
- **Reference Solution**:
  <details>
  <summary><b>View Optimal C# Solution & Complexity</b></summary>

  ```csharp
  public class Solution {
      public bool IsInterleave(string s1, string s2, string s3) {
          if (s1.Length + s2.Length != s3.Length) return false;
          
          int m = s1.Length, n = s2.Length;
          bool[] dp = new bool[n + 1];
          dp[0] = true;
          
          for (int j = 1; j <= n; j++) {
              dp[j] = dp[j - 1] && s2[j - 1] == s3[j - 1];
          }
          
          for (int i = 1; i <= m; i++) {
              dp[0] = dp[0] && s1[i - 1] == s3[i - 1];
              for (int j = 1; j <= n; j++) {
                  char c3 = s3[i + j - 1];
                  dp[j] = (dp[j] && s1[i - 1] == c3) || (dp[j - 1] && s2[j - 1] == c3);
              }
          }
          return dp[n];
      }
  }
  ```
  <b>Complexity:</b> Time: $O(M \cdot N)$, Space: $O(N)$.
  </details>

### Day 7: Memoized Topological DAG on Grids (Longest Increasing Path)
- **Warm-Up (10 mins)**:
  <details>
  <summary><b>🧠 Quick Recall: Why is there no cycle risk in Longest Increasing Path in a Matrix?</b></summary>
  <br>
  <b>Answer:</b> Strict inequality ($\text{neighbor} > \text{current}$) creates an implicit Directed Acyclic Graph (DAG). It is mathematically impossible to have a cycle of strictly increasing values!
  </details>
- **Deep Practice (75–85 mins) | Problem 7**:
  - [Longest Increasing Path in a Matrix](https://leetcode.com/problems/longest-increasing-path-in-a-matrix/) (NeetCode - Hard)
  - Thinking prompts: Use `int[,] memo = new int[m, n]`. DFS returns $1 + \max(\text{neighbors})$.
- **Reference Solution**:
  <details>
  <summary><b>View Optimal C# Solution & Complexity</b></summary>

  ```csharp
  public class Solution {
      public int LongestIncreasingPath(int[][] matrix) {
          int m = matrix.Length, n = matrix[0].Length;
          int[,] memo = new int[m, n];
          int maxPath = 0;
          
          for (int r = 0; r < m; r++) {
              for (int c = 0; c < n; c++) {
                  maxPath = Math.Max(maxPath, Dfs(r, c, matrix, memo));
              }
          }
          return maxPath;
      }
      
      private int Dfs(int r, int c, int[][] matrix, int[,] memo) {
          if (memo[r, c] != 0) return memo[r, c];
          
          int[] dr = { -1, 1, 0, 0 };
          int[] dc = { 0, 0, -1, 1 };
          int longest = 1;
          
          for (int i = 0; i < 4; i++) {
              int nr = r + dr[i];
              int nc = c + dc[i];
              if (nr >= 0 && nr < matrix.Length && nc >= 0 && nc < matrix[0].Length && matrix[nr][nc] > matrix[r][c]) {
                  longest = Math.Max(longest, 1 + Dfs(nr, nc, matrix, memo));
              }
          }
          return memo[r, c] = longest;
      }
  }
  ```
  <b>Complexity:</b> Time: $O(M \cdot N)$, Space: $O(M \cdot N)$.
  </details>

### Day 8: Subsequence Matching Frequencies (Distinct Subsequences)
- **Warm-Up (10 mins)**:
  <details>
  <summary><b>🧠 Quick Recall: In Distinct Subsequences, what happens when $s[i-1] == t[j-1]$?</b></summary>
  <br>
  <b>Answer:</b> We can either use $s[i-1]$ to match $t[j-1]$ (taking $dp[i-1][j-1]$ ways), or skip $s[i-1]$ (taking $dp[i-1][j]$ ways). So $dp[i][j] = dp[i-1][j-1] + dp[i-1][j]$.
  </details>
- **Deep Practice (75–85 mins) | Problem 8**:
  - [Distinct Subsequences](https://leetcode.com/problems/distinct-subsequences/) (NeetCode - Hard)
  - Thinking prompts: Backward iteration 1D array to count matching distinct ways.
- **Reference Solution**:
  <details>
  <summary><b>View Optimal C# Solution & Complexity</b></summary>

  ```csharp
  public class Solution {
      public int NumDistinct(string s, string t) {
          int m = s.Length, n = t.Length;
          double[] dp = new double[n + 1]; // Use double to prevent intermediate overflow
          dp[0] = 1;
          
          for (int i = 1; i <= m; i++) {
              for (int j = n; j >= 1; j--) {
                  if (s[i - 1] == t[j - 1]) {
                      dp[j] += dp[j - 1];
                  }
              }
          }
          return (int)dp[n];
      }
  }
  ```
  <b>Complexity:</b> Time: $O(M \cdot N)$, Space: $O(N)$.
  </details>

### Day 9: The Levenshtein Metric (Edit Distance)
- **Warm-Up (10 mins)**:
  <details>
  <summary><b>🧠 Quick Recall: What are the three editing operations in Edit Distance and their corresponding table transitions?</b></summary>
  <br>
  <b>Answer:</b> If characters differ, take $1 + \min(\text{Insert: } dp[i][j-1], \text{Delete: } dp[i-1][j], \text{Replace: } dp[i-1][j-1])$.
  </details>
- **Deep Practice (75–85 mins) | Problem 9**:
  - [Edit Distance](https://leetcode.com/problems/edit-distance/) (NeetCode - Hard)
  - Thinking prompts: Base cases: empty string requires $j$ insertions or $i$ deletions.
- **Reference Solution**:
  <details>
  <summary><b>View Optimal C# Solution & Complexity</b></summary>

  ```csharp
  public class Solution {
      public int MinDistance(string word1, string word2) {
          int m = word1.Length, n = word2.Length;
          int[] dp = new int[n + 1];
          for (int j = 0; j <= n; j++) dp[j] = j;
          
          for (int i = 1; i <= m; i++) {
              int prevDiag = dp[0];
              dp[0] = i; // Cost of deleting all i characters
              
              for (int j = 1; j <= n; j++) {
                  int temp = dp[j];
                  if (word1[i - 1] == word2[j - 1]) {
                      dp[j] = prevDiag;
                  } else {
                      dp[j] = 1 + Math.Min(prevDiag, Math.Min(dp[j], dp[j - 1]));
                  }
                  prevDiag = temp;
              }
          }
          return dp[n];
      }
  }
  ```
  <b>Complexity:</b> Time: $O(M \cdot N)$, Space: $O(N)$.
  </details>

### Day 10: Interval DP & Boundary Padding (Burst Balloons)
- **Warm-Up (10 mins)**:
  <details>
  <summary><b>🧠 Quick Recall: In Burst Balloons, why is thinking of balloon $k$ as the LAST balloon popped in interval $[l, r]$ optimal?</b></summary>
  <br>
  <b>Answer:</b> If $k$ is popped first, the subproblems on left and right depend on each other. If $k$ is popped LAST, the left and right subproblems $[l, k-1]$ and $[k+1, r]$ are completely independent, bounded by $l-1$ and $r+1$!
  </details>
- **Deep Practice (75–85 mins) | Problem 10**:
  - [Burst Balloons](https://leetcode.com/problems/burst-balloons/) (NeetCode - Hard)
  - Thinking prompts: Pad array with 1 at both ends `[1, ...nums, 1]`. Iterate over interval lengths.
- **Reference Solution**:
  <details>
  <summary><b>View Optimal C# Solution & Complexity</b></summary>

  ```csharp
  public class Solution {
      public int MaxCoins(int[] nums) {
          int n = nums.Length;
          int[] padded = new int[n + 2];
          padded[0] = padded[n + 1] = 1;
          for (int i = 0; i < n; i++) padded[i + 1] = nums[i];
          
          int[,] dp = new int[n + 2, n + 2];
          
          // Window length from 1 to n
          for (int len = 1; len <= n; len++) {
              for (int left = 1; left <= n - len + 1; left++) {
                  int right = left + len - 1;
                  for (int k = left; k <= right; k++) {
                      int coins = padded[left - 1] * padded[k] * padded[right + 1]
                                + dp[left, k - 1] + dp[k + 1, right];
                      dp[left, right] = Math.Max(dp[left, right], coins);
                  }
              }
          }
          return dp[1, n];
      }
  }
  ```
  <b>Complexity:</b> Time: $O(N^3)$, Space: $O(N^2)$.
  </details>

### Day 11: Wildcard Star Branching (Regular Expression Matching)
- **Warm-Up (10 mins)**:
  <details>
  <summary><b>🧠 Quick Recall: In Regex Matching, what are the two options when encountering $p[j] == '*'$?</b></summary>
  <br>
  <b>Answer:</b> 1. Zero occurrences: skip the pair entirely ($dp[i][j-2]$); 2. One or more occurrences (if preceding character matches): consume one character of string $S$ ($dp[i-1][j]$).
  </details>
- **Deep Practice (75–85 mins) | Problem 11**:
  - [Regular Expression Matching](https://leetcode.com/problems/regular-expression-matching/) (NeetCode - Hard)
  - Thinking prompts: 2D table handling `.` (any char) and `*` (0 or more preceding).
- **Reference Solution**:
  <details>
  <summary><b>View Optimal C# Solution & Complexity</b></summary>

  ```csharp
  public class Solution {
      public bool IsMatch(string s, string p) {
          int m = s.Length, n = p.Length;
          bool[,] dp = new bool[m + 1, n + 1];
          dp[0, 0] = true;
          
          // Patterns like a*, a*b*, a*b*c* matching empty string
          for (int j = 2; j <= n; j += 2) {
              if (p[j - 1] == '*') dp[0, j] = dp[0, j - 2];
          }
          
          for (int i = 1; i <= m; i++) {
              for (int j = 1; j <= n; j++) {
                  if (p[j - 1] == '*') {
                      // Case 1: 0 occurrences
                      dp[i, j] = dp[i, j - 2];
                      // Case 2: 1+ occurrences
                      if (p[j - 2] == '.' || p[j - 2] == s[i - 1]) {
                          dp[i, j] = dp[i, j] || dp[i - 1, j];
                      }
                  } else if (p[j - 1] == '.' || p[j - 1] == s[i - 1]) {
                      dp[i, j] = dp[i - 1, j - 1];
                  }
              }
          }
          return dp[m, n];
      }
  }
  ```
  <b>Complexity:</b> Time: $O(M \cdot N)$, Space: $O(M \cdot N)$.
  </details>

### Spaced Retrieval Flashcards

<details>
<summary><b>Flashcard 1: Why must the capacity loop run backwards in a 1D 0/1 Knapsack table?</b></summary>
<br>
To prevent double-counting. If we iterate forward, calculating $dp[w]$ could use a previously updated value of $dp[w - weight]$ from the same outer iteration, effectively using the current item multiple times.
</details>

<details>
<summary><b>Flashcard 2: How can Edit Distance between two strings of length $M$ and $N$ be solved using only $O(\min(M, N))$ space?</b></summary>
<br>
Since $dp[i][j]$ depends only on row $i$ and row $i-1$, we keep one 1D array representing the previous row, and track $dp[i-1][j-1]$ using a single temporary variable <code>prevDiag</code>.
</details>

<details>
<summary><b>Flashcard 3: What is the core insight of Interval Dynamic Programming (e.g. Burst Balloons, Matrix Chain Multiplication)?</b></summary>
<br>
We iterate over the window size (length of the subarray) in the outermost loop ($len = 1 \dots N$). This guarantees that all smaller sub-intervals are completely resolved before solving larger enclosing intervals.
</details>
