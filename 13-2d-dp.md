## 1. Active Recall Pre-Test (15 Minutes)
Attempt to answer these questions on paper before expanding the solutions.

<details>
<summary><strong>Prompt 1: In the 0/1 Knapsack problem, why MUST the inner loop over capacity iterate in REVERSE (from $W$ down to $\text{weight}$) when compressing the DP table to a 1D array?</strong></summary>

In 0/1 Knapsack, each item may be used at most **once**. 
The recurrence is:
$$dp[w] = \max(dp_{\text{old}}[w], \text{val} + dp_{\text{old}}[w - \text{weight}])$$
If we iterate forwards from $\text{weight} \to W$, updating $dp[w]$ would overwrite the slot with a value computed using the *current* item. A later slot $dp[w']$ with $w' > w$ would then read that updated value, inadvertently using the same item multiple times (transforming the solution into an Unbounded Knapsack!). 
Iterating backwards guarantees that $dp[w - \text{weight}]$ still holds the pristine value from the *previous* item layer ($dp_{\text{old}}$).
</details>

<details>
<summary><strong>Prompt 2: What are the three state transitions in the Edit Distance (Levenshtein Distance) matrix?</strong></summary>

Let $dp[i][j]$ be the minimum edits to convert $S_1[0 \dots i-1]$ into $S_2[0 \dots j-1]$:
1. If characters match ($S_1[i-1] == S_2[j-1]$): No cost added:
   $$dp[i][j] = dp[i-1][j-1]$$
2. If characters differ ($S_1[i-1] \ne S_2[j-1]$): Cost is $1 + \min(\dots)$:
   - **Insert**: $1 + dp[i][j-1]$
   - **Delete**: $1 + dp[i-1][j]$
   - **Replace**: $1 + dp[i-1][j-1]$
</details>

<details>
<summary><strong>Prompt 3: How does Longest Common Subsequence (LCS) form the foundational backbone for git diff and bioinformatics sequence alignment?</strong></summary>

A `diff` between two files $A$ and $B$ identifies lines unchanged versus lines added or removed. 
The unchanged lines that preserve top-to-bottom ordering correspond precisely to the **Longest Common Subsequence** of the lines. 
Lines in $A$ not in the LCS are deletions (`-`), and lines in $B$ not in the LCS are insertions (`+`). Minimizing edits is mathematically dual to maximizing the LCS.
</details>

### Core Invariants & Mental Model
1. **The Grid State Invariant**: When $dp[i][j]$ depends only on the current row and the row immediately above ($i-1$), space can be compressed from $O(M \times N)$ to $O(N)$ by keeping two rows (`prev_row`, `curr_row`).
2. **Subsequence vs Substring**: Subsequences allow skipping non-matching elements (retaining previous maximum: $\max(dp[i-1][j], dp[i][j-1])$). Substrings require strict spatial continuity; a mismatch immediately resets the state to 0.
3. **Partition Equal Subset Sum Reduction**: Partitioning an array into two subsets of equal sum is mathematically equivalent to the 0/1 Knapsack problem where target capacity $W = \sum \text{nums} / 2$.

## 3. Canonical Code Templates

### Pattern A: Longest Common Subsequence ($O(M \times N)$ Time, $O(M \times N)$ Space)
```python
def longest_common_subsequence(text1: str, text2: str) -> int:
    m, n = len(text1), len(text2)
    # dp[i][j] stores LCS length for text1[0...i-1] and text2[0...j-1]
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if text1[i - 1] == text2[j - 1]:
                dp[i][j] = 1 + dp[i - 1][j - 1]
            else:
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
                
    return dp[m][n]
```

### Pattern B: 0/1 Knapsack 1D Reverse Space Compression ($O(N \times W)$ Time, $O(W)$ Space)
```python
from typing import List

def can_partition(nums: List[int]) -> bool:
    total_sum = sum(nums)
    if total_sum % 2 != 0:
        return False
        
    target = total_sum // 2
    # dp[w] indicates whether a subset sum of w is achievable
    dp = [False] * (target + 1)
    dp[0] = True # Base case: 0 sum is always achievable
    
    for num in nums:
        # Backward scan invariant prevents reusing the same number
        for w in range(target, num - 1, -1):
            dp[w] = dp[w] or dp[w - num]
            
    return dp[target]
```

### Pattern C: Edit Distance ($O(M \times N)$ Time, $O(N)$ Space)
```python
def min_distance(word1: str, word2: str) -> int:
    m, n = len(word1), len(word2)
    # prev[j] stores min distance for word1[:i-1] to word2[:j]
    prev = list(range(n + 1))
    
    for i in range(1, m + 1):
        curr = [i] + [0] * n
        for j in range(1, n + 1):
            if word1[i - 1] == word2[j - 1]:
                curr[j] = prev[j - 1]
            else:
                curr[j] = 1 + min(
                    prev[j],     # Delete from word1
                    curr[j - 1], # Insert into word1
                    prev[j - 1]  # Replace character
                )
        prev = curr
        
    return prev[n]
```

## 4. Coding Deep Dive: Worked Walkthrough (50 Minutes)

### Problem: Longest Common Subsequence (LeetCode 1143)
**Problem Statement**: Given two strings `text1` and `text2`, return the length of their longest common subsequence.

#### Pen-and-Paper Dry Run Trace
Let `text1 = "abcde"`, `text2 = "ace"`.
Dimensions: $M = 5, N = 3$. Table size: $6 \times 4$.

| `dp[i][j]` | `""` (0) | `'a'` (1) | `'c'` (2) | `'e'` (3) |
|:---:|:---:|:---:|:---:|:---:|
| **`""` (0)** | 0 | 0 | 0 | 0 |
| **`'a'` (1)** | 0 | **1** (`1+dp[0][0]`) | 1 | 1 |
| **`'b'` (2)** | 0 | 1 | 1 | 1 |
| **`'c'` (3)** | 0 | 1 | **2** (`1+dp[2][1]`) | 2 |
| **`'d'` (4)** | 0 | 1 | 2 | 2 |
| **`'e'` (5)** | 0 | 1 | 2 | **3** (`1+dp[4][2]`) |

Result: `dp[5][3] = 3` (Subsequence: `"ace"`).
Time Complexity: $O(M \times N) = 5 \times 3 = 15$ operations.
Space Complexity: Compressed to $O(N) = O(3)$ using rolling rows.

## 6. Post-Session Active Recall Flashcards (15 Minutes)

<details>
<summary><strong>Flashcard 1: How does Target Sum (assigning '+' or '-' to each number to reach target $S$) mathematically reduce to 0/1 Knapsack?</strong></summary>

Let $P$ be the subset of numbers with positive signs, and $N$ be the subset with negative signs.
$$\sum(P) - \sum(N) = S$$
$$\sum(P) + \sum(N) = \text{total\_sum}$$
Adding the two equations:
$$2 \sum(P) = S + \text{total\_sum} \implies \sum(P) = \frac{S + \text{total\_sum}}{2}$$
The problem is mathematically identical to finding the number of subsets with sum exactly equal to $(S + \text{total\_sum}) / 2$. If $S + \text{total\_sum} < 0$ or odd, the answer is 0.
</details>

<details>
<summary><strong>Flashcard 2: In Best Time to Buy and Sell Stock with Cooldown, what are the three state transitions?</strong></summary>

1. `held`: Currently holding stock.
   $$\text{held} = \max(\text{held}, \text{reset} - \text{price})$$
2. `sold`: Sold stock today (enters cooldown tomorrow).
   $$\text{sold} = \text{held} + \text{price}$$
3. `reset`: In cooldown or doing nothing.
   $$\text{reset} = \max(\text{reset}, \text{sold})$$
All three states update concurrently in $O(1)$ space.
</details>

<details>
<summary><strong>Flashcard 3: How do you know whether a 2D matrix search problem should be solved with Dijkstra/BFS vs DFS + Memoization?</strong></summary>

If the transitions contain **cycles** (you can move up, down, left, right freely without restriction), it is a graph shortest path problem (use BFS or Dijkstra). 
If the transitions are **strictly monotonic** (e.g., in Longest Increasing Path, you can *only* step to strictly greater values, preventing cycles), the graph is an implicit **Directed Acyclic Graph (DAG)**, which can be evaluated via DFS + Memoization (Dynamic Programming) in $O(M \times N)$ time.
</details>
