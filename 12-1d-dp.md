# 1-D Dynamic Programming

---

## 🛠️ C# Mental Model & Gotchas

### 1. The Two Pillars of Dynamic Programming
- **Optimal Substructure**: The optimal solution to the overall problem is constructed from optimal solutions to its subproblems.
- **Overlapping Subproblems**: The same subproblems are computed repeatedly.

### 2. State Reduction Invariant
Whenever the recurrence relation at step $i$ only depends on a constant number of previous states (e.g. $dp[i] = f(dp[i-1], dp[i-2])$), **never allocate a full array `int[] dp = new int[n]`**.
Use two rolling variables:
```csharp
int prev2 = base1;
int prev1 = base2;
for (int i = 2; i < n; i++) {
  int curr = f(prev1, prev2);
  prev2 = prev1;
  prev1 = curr;
}
```

This reduces memory from $O(N)$ auxiliary heap allocations to $O(1)$ stack registers, eliminating garbage collection overhead.

### 3. Sentinel Infinity in C#
When finding minimum costs, initializing with `int.MaxValue` risks arithmetic overflow if you add to it (`int.MaxValue + 1 = int.MinValue`). Always use a safe sentinel like `int.MaxValue / 2` or `1e9`.

### Day 2: Min Cost Accumulation
- **Warm-Up (10 mins)**:

<details markdown="1">
<summary><b>🧠 Quick Recall: In Min Cost Climbing Stairs, what is the recurrence relation for the minimum cost to reach step $i$?</b></summary>

<b>Answer:</b> $dp[i] = cost[i] + \min(dp[i-1], dp[i-2])$. The cost to reach the top past step $N-1$ is $\min(dp[N-1], dp[N-2])$.

</details>

- **Deep Practice (75–85 mins) | Problem 2**:
  - [Min Cost Climbing Stairs](https://leetcode.com/problems/min-cost-climbing-stairs/) (NeetCode - Easy)
  - Thinking prompts: Optimize space from $O(N)$ to $O(1)$.
- **Reference Solution**:

<details markdown="1">
<summary><b>View Optimal C# Solution & Complexity</b></summary>

```csharp
public class Solution {
    public int MinCostClimbingStairs(int[] cost) {
        int downOne = 0;
        int downTwo = 0;

        for (int i = 2; i <= cost.Length; i++) {
            int current = Math.Min(downOne + cost[i - 1], downTwo + cost[i - 2]);
            downTwo = downOne;
            downOne = current;
        }
        return downOne;
    }
}
```

<b>Complexity:</b> Time: $O(N)$, Space: $O(1)$.

</details>

### Day 3: Non-Adjacent Choice State (House Robber)
- **Warm-Up (10 mins)**:

<details markdown="1">
<summary><b>🧠 Quick Recall: What are the two mutually exclusive choices when at house $i$ in House Robber?</b></summary>

<b>Answer:</b> Choice 1: Rob house $i$ (yielding $nums[i] + \text{max\_loot}[i-2]$); Choice 2: Skip house $i$ (keeping $\text{max\_loot}[i-1]$).

</details>

- **Deep Practice (75–85 mins) | Problem 3**:
  - [House Robber](https://leetcode.com/problems/house-robber/) (NeetCode - Medium)
  - Thinking prompts: Recurrence $dp[i] = \max(dp[i-1], dp[i-2] + nums[i])$. Maintain `rob1` and `rob2`.
- **Reference Solution**:

<details markdown="1">
<summary><b>View Optimal C# Solution & Complexity</b></summary>

```csharp
public class Solution {
    public int Rob(int[] nums) {
        int rob1 = 0, rob2 = 0;

        // [rob1, rob2, n, n+1, ...]
        foreach (int n in nums) {
            int temp = Math.Max(rob2, rob1 + n);
            rob1 = rob2;
            rob2 = temp;
        }
        return rob2;
    }
}
```

<b>Complexity:</b> Time: $O(N)$, Space: $O(1)$.

</details>

### Day 4: Circular Boundary Decomposition (House Robber II)
- **Warm-Up (10 mins)**:

<details markdown="1">
<summary><b>🧠 Quick Recall: How do you decouple the circular dependency between house 0 and house $N-1$ in House Robber II?</b></summary>

<b>Answer:</b> Split into two linear subproblems: 1. Rob houses $[0 \dots N-2]$ (excluding the last house); 2. Rob houses $[1 \dots N-1]$ (excluding the first house). The answer is $\max(\text{case 1}, \text{case 2})$.

</details>

- **Deep Practice (75–85 mins) | Problem 4**:
  - [House Robber II](https://leetcode.com/problems/house-robber-ii/) (NeetCode - Medium)
  - Thinking prompts: Reuse the House Robber I helper function across slices `[0 .. n-2]` and `[1 .. n-1]`.
- **Reference Solution**:

<details markdown="1">
<summary><b>View Optimal C# Solution & Complexity</b></summary>

```csharp
public class Solution {
    public int Rob(int[] nums) {
        if (nums.Length == 1) return nums[0];
        return Math.Max(RobLinear(nums, 0, nums.Length - 2),
                        RobLinear(nums, 1, nums.Length - 1));
    }

    private int RobLinear(int[] nums, int start, int end) {
        int rob1 = 0, rob2 = 0;
        for (int i = start; i <= end; i++) {
            int temp = Math.Max(rob2, rob1 + nums[i]);
            rob1 = rob2;
            rob2 = temp;
        }
        return rob2;
    }
}
```

<b>Complexity:</b> Time: $O(N)$, Space: $O(1)$.

</details>

### Day 5: Expanding Symmetry (Longest Palindromic Substring)
- **Warm-Up (10 mins)**:

<details markdown="1">
<summary><b>🧠 Quick Recall: How many potential palindrome centers exist in a string of length $N$?</b></summary>

<b>Answer:</b> $2N - 1$ centers ($N$ single-character odd centers and $N - 1$ between-character even centers).

</details>

- **Deep Practice (75–85 mins) | Problem 5**:
  - [Longest Palindromic Substring](https://leetcode.com/problems/longest-palindromic-substring/) (NeetCode - Medium)
  - Thinking prompts: Expand outward from each center $(i, i)$ and $(i, i + 1)$.
- **Reference Solution**:

<details markdown="1">
<summary><b>View Optimal C# Solution & Complexity</b></summary>

```csharp
public class Solution {
    public string LongestPalindrome(string s) {
        int start = 0, maxLen = 0;

        for (int i = 0; i < s.Length; i++) {
            // Odd length palindromes
            Expand(s, i, i, ref start, ref maxLen);
            // Even length palindromes
            Expand(s, i, i + 1, ref start, ref maxLen);
        }
        return s.Substring(start, maxLen);
    }

    private void Expand(string s, int l, int r, ref int start, ref int maxLen) {
        while (l >= 0 && r < s.Length && s[l] == s[r]) {
            if (r - l + 1 > maxLen) {
                start = l;
                maxLen = r - l + 1;
            }
            l--;
            r++;
        }
    }
}
```

<b>Complexity:</b> Time: $O(N^2)$, Space: $O(1)$.

</details>

### Day 6: Prefix Validity & Jump Decomposition (Decode Ways)
- **Warm-Up (10 mins)**:

<details markdown="1">
<summary><b>🧠 Quick Recall: In Decode Ways, when is a two-digit slice $s[i-2 \dots i-1]$ valid?</b></summary>

<b>Answer:</b> When its integer value is between $10$ and $26$ inclusive (e.g. no leading zero like '06').

</details>

- **Deep Practice (75–85 mins) | Problem 6**:
  - [Decode Ways](https://leetcode.com/problems/decode-ways/) (NeetCode - Medium)
  - Thinking prompts: Similar to Fibonacci, but transitions are gated by character validity.
- **Reference Solution**:

<details markdown="1">
<summary><b>View Optimal C# Solution & Complexity</b></summary>

```csharp
public class Solution {
    public int NumDecodings(string s) {
        if (string.IsNullOrEmpty(s) || s[0] == '0') return 0;

        int n = s.Length;
        int prev2 = 1; // dp[i-2]
        int prev1 = 1; // dp[i-1]

        for (int i = 2; i <= n; i++) {
            int current = 0;
            int oneDigit = s[i - 1] - '0';
            int twoDigits = int.Parse(s.Substring(i - 2, 2));

            if (oneDigit >= 1 && oneDigit <= 9) current += prev1;
            if (twoDigits >= 10 && twoDigits <= 26) current += prev2;

            prev2 = prev1;
            prev1 = current;
        }
        return prev1;
    }
}
```

<b>Complexity:</b> Time: $O(N)$, Space: $O(1)$.

</details>

### Day 7: Unbounded Optimal Combination (Coin Change)
- **Warm-Up (10 mins)**:

<details markdown="1">
<summary><b>🧠 Quick Recall: What is the recurrence relation for the minimum coins to make amount $a$?</b></summary>

<b>Answer:</b> $dp[a] = 1 + \min_{c \in coins, c \le a}(dp[a - c])$.

</details>

- **Deep Practice (75–85 mins) | Problem 7**:
  - [Coin Change](https://leetcode.com/problems/coin-change/) (NeetCode - Medium)
  - Thinking prompts: Initialize `dp` table with `amount + 1`. Base case `dp[0] = 0`.
- **Reference Solution**:

<details markdown="1">
<summary><b>View Optimal C# Solution & Complexity</b></summary>

```csharp
public class Solution {
    public int CoinChange(int[] coins, int amount) {
        int[] dp = new int[amount + 1];
        Array.Fill(dp, amount + 1);
        dp[0] = 0;

        for (int a = 1; a <= amount; a++) {
            foreach (int c in coins) {
                if (a - c >= 0) {
                    dp[a] = Math.Min(dp[a], 1 + dp[a - c]);
                }
            }
        }
        return dp[amount] > amount ? -1 : dp[amount];
    }
}
```

<b>Complexity:</b> Time: $O(\text{amount} \times C)$ where $C$ is coin count, Space: $O(\text{amount})$.

</details>

### Day 8: Sign Flip Dual-State Tracking (Maximum Product Subarray)
- **Warm-Up (10 mins)**:

<details markdown="1">
<summary><b>🧠 Quick Recall: Why must we maintain both running maximum AND running minimum in Maximum Product Subarray?</b></summary>

<b>Answer:</b> Multiplying a negative number by a very large negative number flips the sign, transforming a minimal negative value into a maximal positive product!

</details>

- **Deep Practice (75–85 mins) | Problem 8**:
  - [Maximum Product Subarray](https://leetcode.com/problems/maximum-product-subarray/) (NeetCode - Medium)
  - Thinking prompts: When `nums[i] < 0`, swap `curMax` and `curMin` before updating.
- **Reference Solution**:

<details markdown="1">
<summary><b>View Optimal C# Solution & Complexity</b></summary>

```csharp
public class Solution {
    public int MaxProduct(int[] nums) {
        int globalMax = nums[0];
        int curMax = 1, curMin = 1;

        foreach (int n in nums) {
            if (n < 0) {
                (curMax, curMin) = (curMin, curMax);
            }
            curMax = Math.Max(n, curMax * n);
            curMin = Math.Min(n, curMin * n);

            globalMax = Math.Max(globalMax, curMax);
        }
        return globalMax;
    }
}
```

<b>Complexity:</b> Time: $O(N)$, Space: $O(1)$.

</details>

### Day 9: Boolean Reachability over Dictionary (Word Break)
- **Warm-Up (10 mins)**:

<details markdown="1">
<summary><b>🧠 Quick Recall: What does $dp[i] = true$ mean in Word Break?</b></summary>

<b>Answer:</b> The substring $s[0 \dots i-1]$ can be completely segmented into valid dictionary words.

</details>

- **Deep Practice (75–85 mins) | Problem 9**:
  - [Word Break](https://leetcode.com/problems/word-break/) (NeetCode - Medium)
  - Thinking prompts: `dp[i] = true` if there exists some $j < i$ where `dp[j] == true` and $s[j \dots i-1]$ is in dictionary set.
- **Reference Solution**:

<details markdown="1">
<summary><b>View Optimal C# Solution & Complexity</b></summary>

```csharp
public class Solution {
    public bool WordBreak(string s, IList<string> wordDict) {
        HashSet<string> words = new(wordDict);
        bool[] dp = new bool[s.Length + 1];
        dp[0] = true;

        for (int i = 1; i <= s.Length; i++) {
            for (int j = 0; j < i; j++) {
                if (dp[j] && words.Contains(s.Substring(j, i - j))) {
                    dp[i] = true;
                    break;
                }
            }
        }
        return dp[s.Length];
    }
}
```

<b>Complexity:</b> Time: $O(N^2 \cdot L)$ where $L$ is word length, Space: $O(N)$.

</details>

### Day 10: Patience Sorting Binary Search (Longest Increasing Subsequence)
- **Warm-Up (10 mins)**:

<details markdown="1">
<summary><b>🧠 Quick Recall: How does Patience Sorting achieve $O(N \log N)$ for LIS?</b></summary>

<b>Answer:</b> Maintain an array <code>tails</code> where <code>tails[i]</code> stores the smallest tail of all increasing subsequences of length $i+1$. For each number, binary search the leftmost element $\ge x$ in <code>tails</code> and overwrite it. If $x$ is larger than all elements, append it.

</details>

- **Deep Practice (75–85 mins) | Problem 10**:
  - [Longest Increasing Subsequence](https://leetcode.com/problems/longest-increasing-subsequence/) (NeetCode - Medium)
  - Thinking prompts: Compare $O(N^2)$ standard DP with $O(N \log N)$ Patience Sort via `Array.BinarySearch()`.
- **Reference Solution**:

<details markdown="1">
<summary><b>View Optimal C# Solution & Complexity</b></summary>

```csharp
public class Solution {
    public int LengthOfLIS(int[] nums) {
        List<int> tails = new();

        foreach (int x in nums) {
            int idx = tails.BinarySearch(x);
            if (idx < 0) idx = ~idx; // Bitwise complement returns insertion index

            if (idx == tails.Count) {
                tails.Add(x);
            } else {
                tails[idx] = x;
            }
        }
        return tails.Count;
    }
}
```

<b>Complexity:</b> Time: $O(N \log N)$, Space: $O(N)$.

</details>

### Spaced Retrieval Flashcards

<details markdown="1">
<summary><b>Flashcard 1: When can you optimize space in a 1D DP table from $O(N)$ to $O(1)$?</b></summary>

When $dp[i]$ only requires values from a fixed window of preceding states (e.g. $dp[i-1]$ and $dp[i-2]$). Replacing the array with rolling variables reduces memory allocations to zero.
</details>

<details markdown="1">
<summary><b>Flashcard 2: In C#, what does <code>List&lt;int&gt;.BinarySearch(x)</code> return if $x$ is not found?</b></summary>

It returns a negative number whose bitwise complement (<code>~idx</code>) is the index of the first element that is larger than $x$ (the insertion point).
</details>

<details markdown="1">
<summary><b>Flashcard 3: What is the difference between Coin Combinations I (permutations) and Coin Combinations II (combinations)?</b></summary>

In Combinations (unordered), the outer loop iterates over coins and inner over amounts, ensuring each coin type is considered in a fixed order. In Permutations (ordered), the outer loop iterates over amounts and inner over coins.
</details>
